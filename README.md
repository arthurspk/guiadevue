## :dart: O guia para alavancar a sua carreira

> Vue.js é um framework JavaScript progressivo para construir interfaces: você adota só o que precisa — de um `<script>` solto numa página HTML até uma aplicação completa com roteamento, estado global e renderização no servidor via Nuxt. Criado por Evan You e mantido por uma equipe independente (sem uma big tech por trás), o Vue equilibra reatividade automática com uma curva de aprendizado suave e uma documentação oficial considerada uma das melhores do ecossistema JavaScript. Este guia reúne roadmap, cursos gratuitos e pagos, documentação oficial, livros, canais, ferramentas do ecossistema (Nuxt, Pinia, Vite, VueUse), comunidades e um capítulo dedicado a usar IA na prática com Vue — tudo verificado e organizado para quem já sabe JavaScript e quer sair do primeiro componente `.vue` até dominar a Composition API e o Nuxt.

## 🤖 IA na prática

Vue tem uma particularidade que costuma confundir assistentes de IA: coexistem hoje a Options API (mais antiga) e a Composition API (padrão desde o Vue 3), além de projetos legados ainda em Vue 2. Peça sempre código para a versão que o seu projeto realmente usa.

**Para aprender**

- Peça para a IA explicar a diferença entre `ref()` e `reactive()` com um exemplo do seu próprio código — é a dúvida mais comum de quem começa.
- Cole um componente em Options API e peça: "reescreva isso em Composition API com `<script setup>`, seguindo a documentação oficial do Vue 3".
- Peça exercícios com gabarito sobre o tópico que está estudando (props e emits, watchers, `provide`/`inject`, slots).
- Peça para comparar Pinia vs. Vuex vs. `provide`/`inject` para gerenciar um estado específico, com prós e contras.

**Para trabalhar**

- Use o [GitHub Copilot](https://github.com/features/copilot), o [Cursor](https://cursor.com/) ou o [Claude Code](https://code.claude.com/docs/en/overview) para: gerar componentes `.vue` a partir de uma descrição, escrever testes com o [Vue Test Utils](https://test-utils.vuejs.org/), migrar componentes de Options API para Composition API e criar variações de UI com o [PrimeVue](https://primevue.dev/) ou o [Vuetify](https://vuetifyjs.com/).
- Depois de **cada** sugestão aceita, rode a checagem de tipos (`vue-tsc`) e o [eslint-plugin-vue](https://eslint.vuejs.org/). Se o código quebra a sintaxe do `<script setup>` ou mistura as duas APIs sem necessidade, a sugestão está errada, mesmo que "funcione".
- Em projetos [Nuxt](https://nuxt.com/), confira se a IA não está importando manualmente algo que já é auto-importado (componentes, composables, utils) — isso costuma gerar erros de build silenciosos.

**Limites e boas práticas**

- IA mistura com frequência a sintaxe do Vue 2 (`this.$emit`, prop `value` + evento `input` no `v-model`) com a do Vue 3 (`modelValue` + `update:modelValue`, múltiplos `v-model` desde a versão 3.4). Confirme sempre na [documentação oficial](https://vuejs.org/api/).
- `defineProps`, `defineEmits` e `defineModel` são macros do compilador, não funções importadas de `'vue'` — se a IA sugerir `import { defineProps } from 'vue'`, ela está errada.
- Cuidado com código gerado para Nuxt que mistura contexto de servidor e cliente (ex.: usar `window` fora de um hook `onMounted` ou de uma checagem `import.meta.client`).
- Não cole código proprietário, chaves de API ou dados de clientes em ferramentas sem a política da sua empresa.
- Entenda o que você aceita: em entrevista e em produção, o código é seu.

## 🎓 Certificações

Vue.js não tem uma certificação "oficial" mantida pela equipe do framework — o que mais conta no mercado ainda são projetos publicados e domínio prático da Composition API. Um certificado ajuda a complementar o currículo:

- [Learn Vue.js (Codecademy)](https://www.codecademy.com/learn/learn-vue-js) — Curso gratuito com certificado de conclusão disponível para assinantes dos planos pagos Plus/Pro.
